# Website Portofolio Mahasiswa Sistem Informasi

Website portofolio sederhana untuk mahasiswa Sistem Informasi semester 4. Dibuat dengan HTML, CSS, dan JavaScript, sehingga bisa langsung dipublikasikan lewat GitHub Pages.

## Isi Website

- Beranda dengan ringkasan profil
- Tentang saya
- Keahlian
- Proyek
- Kontak

## Cara Mengedit

1. Buka `index.html`.
2. Ganti `Nama Kamu`, email, link GitHub, dan link LinkedIn.
3. Sesuaikan daftar proyek pada bagian `id="proyek"`.
4. Jika ingin mengubah warna atau tampilan, edit `style.css`.

## Cara Upload ke GitHub

1. Buat repository baru di GitHub, misalnya `portofolio`.
2. Upload semua file ini ke repository tersebut:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Buka menu `Settings` repository.
4. Pilih `Pages`.
5. Pada bagian `Build and deployment`, pilih `Deploy from a branch`.
6. Pilih branch `main` dan folder `/root`.
7. Klik `Save`.

Setelah aktif, website biasanya bisa dibuka lewat:

```text
https://username.github.io/portofolio/
```
